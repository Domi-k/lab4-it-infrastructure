## 📌 Назначение проекта

Данный проект представляет собой упрощенный агент инвентаризации и мониторинга ресурсов компьютера на языке Python. Программа собирает сведения об аппаратных и сетевых ресурсах, генерирует технический паспорт устройства в формате JSON, выполняет автоматический анализ конфигурации, а также осуществляет мониторинг нагрузки с фиксацией пороговых значений.

---

## 📁 Структура проекта

* `inventory.py` — скрипт автоматической инвентаризации (сбор данных о CPU, RAM, дисках, сетевых интерфейсах IPv4/MAC и генерация рекомендаций).
* `monitor.py` — скрипт мониторинга ресурсов (CPU, RAM, DISK, SWAP) с заданной частотой и записью логов в CSV.
* `passport_192.168.0.59.json` — сгенерированный технический паспорт устройства в формате JSON.
* `monitor_log.csv` — журнал замеров нагрузки с отметками о превышении порогов.
* `README.md` — документация к проекту.

## ⚙️ Параметры варианта (Вариант 2)

* **Интервал замеров (`INTERVAL`):** 2 секунды
* **Количество замеров (`SAMPLES`):** 20
* **Пороговые значения (`THRESHOLDS`):** 
  * CPU: 75%
  * RAM: 85%
  * DISK: 90%
* **Дополнительная метрика:** Загрузка файла подкачки (SWAP, %) — `psutil.swap_memory().percent`
